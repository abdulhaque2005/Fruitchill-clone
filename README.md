# 🍧 FruitChill Pops Clone  

## 🚀 Overview  
This project is a fully responsive clone of the FruitChill Pops website, created using only HTML5 and CSS3. The main goal of this project was to practice real-world frontend development by replicating a live website design without using JavaScript or any frameworks.  

The design focuses on clean UI, proper layout structure, and responsiveness across all devices including mobile, tablet, and desktop screens. This project helped in improving my understanding of Flexbox, positioning, spacing, and responsive design techniques.  

It is a beginner-friendly project that demonstrates how modern websites can be built using only core web technologies.  

---

## 🎯 Features  
- Fully responsive design  
- Built using only HTML & CSS  
- Clean and modern UI  
- Real-world website clone practice  
- Mobile, tablet, and desktop compatible
